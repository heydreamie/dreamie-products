# 书间 · 阅读标本室

把书、摘录、阅读感受和 PDF 页码放进自己的阅读室。

[在线体验空白阅读室](https://heydreamie.com/projects/reading-herbarium/app/index.html) · [产品介绍](https://heydreamie.com/site/islands/memories/reading-herbarium/index.html) · [回到产品目录](../README.md)

![书间产品界面](https://heydreamie.com/site/islands/memories/media/reading-product.png)

## 可以体验什么

- 在立体书架中管理阅读状态，导入自己的 PDF。
- 阅读、划选有文字层的原文，保存带书籍和页码的摘录。
- 写下理解、问题与小行动，在笔记与回声中继续思考。
- 用植物生长表现摘录、理解和行动之间的关系。

## 数据与版本

网页应用无需注册。PDF 与阅读记录保存在访客当前的浏览器中，不会加入作者的个人书架。

JSON 备份与 PDF 原件需要分别保存。扫描图片页可阅读并手动摘抄，文字划选依赖 PDF 自带文字层；当前没有 OCR。

当前提供网页版，未提供 Android APK。
