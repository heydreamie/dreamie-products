# 练块 · SET BY SET

把每一组训练变成一块可回看的积木。

![练块立体训练记录](https://heydreamie.com/site/islands/memories/media/on-record-bricks.jpg)

## 可以体验什么

- 新建训练组，记录重量与时长，复制已有训练并做微调。
- 用立体积木查看、展开与回放训练，回看积累。
- 导出或导入 JSON 记录，保留自己的备份。
