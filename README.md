## 开始使用

- 想先试试：从各项目的网页入口进入。浏览器与 Android 应用分别保存各自的记录。
- 想安装到手机：使用对应的 Android 下载链接；安装要求、版本信息和已知限制见产品说明。
- 想了解设计过程：每份产品说明都链接到作品集案例，可以继续查看实际界面和设计取舍。

Android 安装包的构建与资源检查不等于真机验收。当前列出的体验／测试版尚未完成真机安装验证，重要记录请及时备份。
